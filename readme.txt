LTKademy – Académie de développement web

Description :
Plateforme de formations en programmation (Python, JavaScript, HTML/CSS, Java, SQL, PHP).
Chaque formation possède une page de détail accessible en cliquant sur la carte (image ou titre). Cette page contient une description complète, le programme, les prérequis, les prix et les durées.

Fonctionnalités :
- Affichage dynamique des formations depuis un tableau JavaScript
- Filtrage par type (frontend / backend) et niveau (débutant / avancé)
- Page détail pour Chaque page
- Panier (ajout, suppression, calcul du total)
- Inscription / Connexion avec validation RegEx (email, téléphone, mot de passe)
- Session utilisateur stockée dans localStorage
- Design responsive (mobile / tablette / desktop)

Instructions d'utilisation :
1. Ouvrir index.html dans un navigateur
2. Créer un compte via la page Inscription
3. Se connecter via la page Connexion
4. Parcourir les formations sur la page Formations
5. Filtrer par type (Frontend / Backend) puis par niveau (Débutant / Avancé)
6. Cliquer sur une carte pour voir la description détaillée de la formation
7. Ajouter des formations au panier
8. Aller dans Réservation, modifier ou supprimer des articles, puis confirmer (connexion obligatoire)
