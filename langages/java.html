Formation Java

Java est un langage puissant, utilisé pour les applications d'entreprise et Android.

Ce que tu vas apprendre :

  • Bases de Java (variables, boucles, conditions)
  • Programmation orientée objet
  • Gestion des exceptions et collections
  • Connexion aux bases de données (JDBC)

Prérequis :

Aucun prérequis technique. La logique de programmation est un plus.
