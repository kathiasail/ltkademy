Formation JavaScript

JavaScript est le langage qui fait vivre les sites web. Sans lui, tout serait figé et sans interaction.

Avec JavaScript tu pourras : animer des pages, créer des jeux, développer des applications mobiles et même du côté serveur avec Node.js.

C'est le langage le plus recherché par les recruteurs aujourd'hui.

Ce que tu vas apprendre :

  • Les bases : variables, fonctions, conditions, boucles
  • Manipuler les pages web (DOM)
  • Créer des interactions utilisateur (clics, formulaires)
  • Travailler avec des API et des données

Prérequis :

Connaître un peu HTML/CSS. Mais on reprend les bases si besoin.
