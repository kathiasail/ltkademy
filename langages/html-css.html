Formation HTML & CSS

HTML et CSS sont les piliers de tout site web. Avec eux, tu peux créer et styler des pages.

HTML donne la structure, CSS apporte le style (couleurs, mise en page, animations...).

Ce que tu vas apprendre :

  • Créer une page HTML propre (titres, paragraphes, images, liens)
  • Appliquer du style CSS (couleurs, polices, espacements)
  • Organiser ta page avec Flexbox et Grid
  • Rendre ton site adaptable aux mobiles (responsive)

Prérequis :

Aucun prérequis technique. Juste un ordinateur et la motivation.
